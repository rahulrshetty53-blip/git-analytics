# Testing Guide

## Unit Tests
Run backend tests:
```bash
cd backend
npm test
```

## Integration Tests
Test GitHub API integration:
```bash
npm run test:github
```

## Frontend Tests
Test React components:
```bash
cd frontend
npm test
```

## End-to-End Tests
Run full application tests:
```bash
npm run test:e2e
```

## Test Coverage
Aim for 80%+ code coverage

## Manual Testing Checklist
- [ ] User signup flow
- [ ] User login flow
- [ ] GitHub token integration
- [ ] Repository sync
- [ ] Analytics calculation
- [ ] Dashboard display
- [ ] Mobile responsiveness
